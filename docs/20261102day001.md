## 思路

### LC0001_TwoSum

- 暴力两重循环 O(n^2)，改用哈希表一次遍历：遍历时先查 `target - nums[i]` 是否已出现过，出现过直接返回两个下标，否则把当前「值 -> 下标」存入表。
- 关键点：先查再存，天然避免同一个元素用两次。

### LC0003_LongestSubstring

- 滑动窗口：`left` 为窗口左边界，`last[c]` 记录字符 c 最近一次出现的位置。
- 当 `last[c] >= left` 说明当前字符在窗口内有重复，把 `left` 直接跳到 `last[c] + 1`。
- 每步用 `i - left + 1` 更新答案。

## 复杂度

| LC0003 | O(n) | O(1) | 字符集固定 128，last 数组为常数空间 |

## 踩坑

- Java 包名不能以数字开头：`20261102day001` 无法编译，最终采用 `_20261102day001`（下划线前缀 + 补零形式），后续每天保持 `_20261103day002` 的格式。
- 滑动窗口去重判断要用 `last[c] >= left` 而不是 `last[c] != -1`，否则左边界会往回跳。
